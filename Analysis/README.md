# Analysis

This directory contains the scripts and configuration needed to launch the WGS Analysis pipeline on the Alliance clusters. The pipeline itself lives in `Analysis/HiFi-human-WGS-WDL/` as a git submodule — see [FelixAntoineLeSieur/HiFi-human-WGS-WDL](https://github.com/FelixAntoineLeSieur/HiFi-human-WGS-WDL) for the fork used here, which includes minor changes to make the pipeline work in the Alliance environment. Samplesheets required as pipeline inputs are generated by the scripts in [Preanalysis](../Preanalysis/README.md).

This folder also contains a script called "exec_script.sh". It is meant to be inserted in the miniwdl_slurm lib folder so miniwdl_slurm can make use of $SLURM_TMPDIR (See [here](../README.md#running-the-scripts) for how to do the insert). It is not meant to be launched manually. 

---

- **tmuxLaunchTrio.sh**
  - *Usage*:
    ```bash
    bash Analysis/tmuxLaunchTrio.sh -i <family_or_sample_ID> [-c config]
    ```
  - *Goal*: Launches the WGS pipeline (`miniwdl run`) for a given family or sample in a **detached tmux session**, so the run survives SSH disconnections. Reads the samplesheet path, miniwdl config, and output directory from the config file.
  - *Arguments*:
    - `-i` — Family or sample ID; must match a samplesheet filename in `sample_sheet_path`.
    - `-c` — Config file (default: `../.myconf.json` relative to the script).
  - *Outputs*: A detached tmux session named `{family_or_sample_ID}` with the pipeline running inside it. Pipeline outputs are written to `output_path/{family_or_sample_ID}/`.

---

## Pipeline submodule

The WGS pipeline lives in `Analysis/HiFi-human-WGS-WDL/`, included as a git submodule. The fork at [FelixAntoineLeSieur/HiFi-human-WGS-WDL](https://github.com/FelixAntoineLeSieur/HiFi-human-WGS-WDL) contains installation instructions and the Alliance-specific modifications.

- **exec_script.sh** — This script replaces the native miniwdl-slurm exec script (`Tools/ENV/lib/python3.11/site-packages/miniwdl_slurm/scripts/exec_script.sh`) to redirect intermediate task files to `$SLURM_TMPDIR` instead of the working directory. This improves I/O performance and overall efficiency on Alliance clusters, where `$SLURM_TMPDIR` is local to the compute node. See the [Requirements section of the main README](../README.md#requirements) for the installation step.
